Project Hub 모바일 자료실

실행 환경: Python 3.11, requirements-web.txt. 웹 서비스는 별도 가상환경으로 실행합니다.
기능: 파일명/본문 검색, 채널 필터, 추출된 본문 열람, 원본 다운로드,
선택한 문서의 AI 요약·질문, 출처 구간 이동, 공유 링크 복사.
수집 봇의 기존 content_* 테이블은 읽기 전용입니다. Markdown, HTML, PPTX는 별도
library-text.db에 본문을 추출해 검색·열람·AI 질문에 사용합니다. HTML 스크립트는 실행하지
않습니다. PPTX는 슬라이드 순서대로 텍스트를 표시하며 원본 배치를 재현하지 않습니다.
PNG/JPEG/GIF/WebP는 이미지 미리보기를 제공합니다. 이미지뿐인 PPTX, 옛 DOC/PPT 형식은
본문 변환 대상이 아닙니다. 여러 문서를 합친 질문은 별도 작업입니다.

접근 방식
- library.env에서 PROJECT_HUB_LIBRARY_PUBLIC=true이면 /library/ 짧은 주소로 모든 자료와
  다운로드·AI에 로그인 없이 접근합니다. 주소를 발견한 사람도 접근할 수 있습니다.
  아래 공유 토큰 제한은 이 옵션을 끈 기본 모드에 적용됩니다.
- 사용자가 받은 https://도메인/library/#key=... 링크로 접속하면 자동으로 세션을 얻습니다.
- 링크 소지자는 모든 수집 자료 열람·다운로드·AI 질문·재공유가 가능합니다.
- 별도 계정, 로그인 폼, OTP가 없습니다. Discord 채널별 사용자 권한도 적용하지 않습니다.
- 링크 없는 사용자는 자료/본문/다운로드/API에 접근할 수 없습니다. 공개되는 것은 빈 UI뿐입니다.
- 토큰은 URL fragment에서 읽어 POST로 교환한 뒤 주소창에서 제거합니다. 서버 접근 로그에
  토큰 URL을 남기지 않으며 Referrer-Policy=no-referrer, noindex, no-store를 설정합니다.
- 공유는 화면의 '공유 링크 복사'를 사용합니다. 주소창에는 토큰이 남지 않습니다.
- 세션 쿠키는 Secure/HttpOnly/SameSite=Strict, /library/ 경로, 14일 유효입니다.
- POST는 설정된 HTTPS origin과 JSON/사용자 정의 헤더를 검사합니다.
- 자료실은 127.0.0.1:8090에서만 수신합니다. Caddy가 /library 및 /library/*만 연결하고,
  기존 code-server 경로는 Authelia 2단계 인증을 계속 거칩니다.
- AI 한도는 모든 링크 사용자가 공유합니다. 기본 하루 20회, 월 300회이며 계정 전체 과금
  상한은 아닙니다. AI는 서버에서 한 번에 하나만 실행하고 다른 요청은 대기 안내를 반환합니다.

Pi 설정 (khb 사용자)
  python -m organizer.share --origin https://khbps.duckdns.org
설정: ~/.config/project-hub/library.env (600)
공유 주소: ~/.config/project-hub/library-share-url.txt (600)
키, 설정, 공유 주소, AI 결과 DB는 Git에 넣지 않습니다.
venv311 준비 후 sudo python3 /home/khb/project-hub/organizer/install_web.py 로 설치합니다.
설치기는 Caddy 설정을 검증·백업하고 서비스 등록 및 /library 경로 연결을 수행합니다.
설정이 예상과 다르면 변경하지 않으며, 시작/연결 실패 시 기존 상태로 복구합니다.
서비스는 PC가 꺼져도 Pi에서 동작하며 Pi 재부팅 후 자동 시작합니다.

링크 폐기·재발급
  python -m organizer.share --origin https://khbps.duckdns.org --rotate
  sudo systemctl restart project-hub-library.service
토큰 모드에서 재시작하면 이전 링크와 기존 세션이 모두 무효화됩니다. 새 URL만 다시 전달하세요.
공개 모드에서는 토큰 교체로 접근을 차단할 수 없습니다. PUBLIC 옵션을 먼저 끄세요.
기존 링크는 --rotate 없이 덮어쓰지 않습니다.

중지
  sudo systemctl stop project-hub-library.service
자동 재시작도 끄려면 disable을 사용합니다. Caddy 경로는 유지되며 자료는 노출되지 않습니다.
운영 확인: systemctl is-active project-hub-library.service / journalctl -u project-hub-library.service

과거 첨부파일 수집 (관리자)
봇을 일시 중지하고 프로젝트 폴더에서 봇의 Python으로 python -m organizer.backfill 실행 후
성공·실패와 무관하게 봇을 다시 시작합니다. 지정 채널 및 포럼의 활성/보관 스레드를 조회하며
기존 중복 판정과 Drive 업로드 대기열을 사용합니다. 일반 대화의 과거 기록은 저장하지 않습니다.
별도 ~/.local/state/project-hub-ai/backfill.db에 진행 지점을 저장해 중단 후 이어서 실행합니다.
이 과정은 실시간 수집 커서를 되돌리지 않습니다. 삭제되었거나 봇이 볼 수 없는 메시지는
복구할 수 없으며 접근 오류가 있으면 채널별 실패를 출력합니다.

본문 미리보기
Drive 업로드가 완료된 파일은 본문 영역의 Drive 미리보기로 표시합니다. 미지원 형식은
Drive로 보기 또는 다운로드를 사용합니다. HTML/HTM은 로컬 페이지를 별도 sandbox iframe에
표시하며 스크립트·폼·외부 리소스 연결을 차단합니다. CSS와 내장 이미지는 표시하지만
스크립트로 생성되는 차트·3D 화면은 동작하지 않을 수 있습니다. 추출 텍스트는 아래에서
펼칠 수 있고, AI 출처를 누르면 해당 텍스트 구간을 펼쳐 표시합니다.

자료 목록은 별도 스크롤을 사용합니다. 채널·확장자·검색을 조합하고 파일명 오름/내림차순,
Discord 업로드 날짜 최신/오래된순으로 전체 결과를 정렬할 수 있습니다. 모바일에서는
상단 메뉴 버튼으로 목록을 열고 닫으며 파일 선택 후에도 필터와 목록 위치를 유지합니다.

모바일은 텍스트가 있으면 편하게 읽기를 기본으로 사용합니다. Word/HTML은 별도 읽기용
블록으로 제목·문단·표를 표시하며 기존 검색/AI 출처 인덱스를 변경하지 않습니다.
Markdown은 제목·목록·표·코드 블록, PDF는 기존 추출 텍스트의 줄바꿈을 정리해 표시합니다.
PDF 다단/표 배치는 정확히 복원되지 않을 수 있습니다. 원본 보기와 글자 확대를 제공합니다.
Word의 이미지·병합 셀·각주와 복잡한 HTML 중첩 구조는 원본에서 확인하세요.

통합 AI
화면의 통합 AI/선택 범위에 질문하기는 목록의 채널·기간에 해당하는 파일과 공개 대화의
최신 본문 색인을 검색합니다. 파일 형식·최신 업로드·파일/대화 종류 필터는 AI에 적용하지 않습니다. 키워드 기반 검색으로 최대 12구간, 파일별 2구간, 합계 12000자
이내를 보냅니다. 관련 내용이 없으면 AI를 호출하지 않습니다. 최근 자료 요약은 최근 파일의
일부 구간 요약이며 전체 자료 요약이 아닙니다.
출처 버튼은 해당 파일의 추출 구간을 엽니다. 기존 일/월 한도와 요청 잠금을 공유합니다.
변환 보기의 이전 이름은 편하게 읽기입니다. HTML 스크립트 차단 정책은 유지됩니다.

공개 대화 검색
로컬 library.env의 PROJECT_HUB_LIBRARY_MESSAGE_CHANNELS에 공개할 채널/포럼 ID를
쉼표로 지정합니다. 기본값은 비어 있으며 수집만으로 대화가 웹에 공개되지는 않습니다.
포럼 ID는 해당 포럼의 저장된 게시글 대화를 포함합니다. 웹이 공개 모드이면 대화 본문과
작성자명도 공개됩니다. 공개 범위 변경에는 사용자의 의사 확인이 필요합니다.
파일/대화 전환, 채널 필터, 전체/최근 7일/30일, 더 보기를 제공합니다. 대화는 최신순이며
본문에서 Discord 원문과 같은 메시지의 첨부 파일을 열 수 있습니다.
AI는 파일 최대 12구간과 대화 최대 12개를 합계 12000자 이내에서 참고합니다. 대화가 있으면
최대 절반의 입력 예산을 할당합니다. 키워드 검색은 의미가 비슷한 모든 대화를 찾는 검색이
아닙니다. 날짜는 선택한 기간으로 제한하며 '이번 주' 등의 자연어 날짜를 자동 해석하지 않습니다.
삭제 표시된 대화는 제외하며 답변 생성 중 수정/삭제가 확인되면 결과를 반환하지 않습니다.
Discord 원문 링크를 열 때는 별도로 해당 서버/채널의 Discord 접근 권한이 필요합니다.

질문할 때 검색된 대화 최대 6개에 같은 서버·같은 채널/게시글의 앞뒤 15분 대화와
직접 답글/답글 원문을 추가합니다. 답글은 15분 밖이어도 선택한 기간 안이면 포함하며,
전체 대화 수·입력 글자 한도 안에서 일부만 참고합니다. 주변 대화는 시간상 가까운
참고 맥락이며 같은 주제나 최종 결정임을 보장하지 않습니다. 각 메시지의 출처는 유지합니다.
선택된 대화의 첨부파일은 본문 키워드가 일치하지 않아도 기존 추출 색인에서 참고할 수 있습니다.
본문 추출이 불가능하거나 아직 처리되지 않은 첨부파일은 파일명만 보일 수 있습니다.

최근 7일 정리
상단 버튼에서 최근 파일·공개 대화 목록과 마지막으로 저장한 정리를 확인합니다.
생성 버튼을 누를 때만 AI를 호출하며 기존 사용 한도와 캐시를 공유합니다.
파일 업로드 시각과 대화 작성 시각 모두 최근 7일로 제한하고 일부 본문만 참고합니다.
주제·핵심 요약·결정사항·할 일·확인 필요 항목을 출처와 함께 정리합니다.
weekly-summary.json에 최신 결과 하나를 저장하며 Git에서는 제외합니다.
대화 수정·삭제·공개 범위 변경 또는 파일 변경 시 이전 결과를 숨깁니다.
생성 시각을 표시하며 자동 갱신하지 않습니다. 원본 백업으로 다시 생성할 수 있습니다.

중복·버전 보기
목록에 동일 내용 건수, 같은 채널·파일명의 내용 종류 수, 최신/이전 업로드를 표시합니다.
동일 내용은 비어 있지 않은 SHA-256 일치 기준이며 다른 파일명으로 올라온 자료도 연결합니다.
같은 채널·같은 파일명은 수정본 후보이며 확정된 버전 관계를 뜻하지 않습니다.
최신 업로드 필터는 날짜를 UTC 기준으로 비교하며 동률이면 기록 ID가 큰 파일을 표시합니다.
최신 그룹을 먼저 고른 뒤 검색·확장자·채널 필터를 적용하므로 이전 본문만 일치하면 나오지 않습니다.
상세 화면은 동일 파일·이전 업로드 최대 50건을 표시합니다. 원본과 저장된 버전 정보는 바꾸지 않습니다.
새 통합 AI 답변의 파일 출처에는 업로드 날짜를 표시합니다.

통합 검색
기본 파일 + 대화에서 두 종류를 한 번에 조회하며 검색어 주변 본문을 텍스트로 표시합니다.
더 보기는 파일 30개·대화 20개씩 추가합니다. 종류별 한도를 적용하므로 전체 검색 결과의 통합 순위는 아닙니다.
파일만 선택하면 확장자·최신 업로드·정렬을 사용할 수 있습니다.
기간은 파일 업로드일과 대화 작성일을 기준으로 전체/최근 7일/30일을 선택합니다.
선택한 채널·기간은 통합 AI에도 적용하며 포럼 선택 시 해당 게시글과 첨부파일을 포함합니다.
검색은 AI를 호출하지 않습니다. 최근 7일 정리 화면은 기존처럼 전체 채널의 주간 자료를 참고합니다.

자료 바로가기·처리 상태
파일은 /library/?file=기록ID, 대화는 /library/?message=메시지ID로 직접 열 수 있습니다.
자료 화면의 이 자료 주소 복사 또는 상단 주소 복사는 현재 열린 자료 주소를 복사합니다.
공유키 모드에서는 기존 키를 보존하며 삭제·공개 범위 밖 대화는 직접 주소로도 열리지 않습니다.
자료 목록의 수집·처리 상태는 등록된 파일의 본문 처리와 Drive 업로드 건수를 표시합니다.
상태 조회는 변환을 실행하지 않고 현재 DB·캐시의 동일 해시 결과만 읽습니다.
최근 5분 안에 공개 대상 채널의 수집 확인이 모두 성공한 경우에만 정상으로 표시합니다.
아직 DB에 등록되지 않은 다운로드 중 파일은 상태 건수에 포함되지 않습니다.
개별 파일에는 수집 완료, 본문 상태, Drive 상태를 구분하여 표시하며 raw 오류·로컬 경로는 공개하지 않습니다.
